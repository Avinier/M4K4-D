# Generated body v1 reports

Run `python write_outputs.py` from the parent `cad/` directory with the CAD Python environment to produce `dimensions.json`, `frames.json`, `mass-properties.json`, `dimensions.md`, and `mass-properties.md`. The Python model is the source of truth; regenerate these after changing its parameters.

The mass report includes a partial body-row subset and the whole-robot body-v1 estimate. `body-layout-checks.json` is generated by `check_body_layout.py` and verifies the shell/frame rows against their CAD volumes, as well as the current axes, envelope, support share, skid ordering, and neutral/bounded-head stability screens. These are material-density estimates, not weighed assembly mass or measured lift onset.
