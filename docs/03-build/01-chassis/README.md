# 01 — Chassis and locomotion

The [v1 BOM](v1/BOM.md) lists installed chassis quantities, shared parts needed for a powered rolling test, and the open decisions that prevent release. The [project BOM](../BOM.csv) is the canonical register for sourcing and status. The [v1 CAD starting point](v1/cad/README.md) defines the current model boundary and exclusions.

The v1 snapshot is a working list. Freeze it only after purchased parts are received and measured, custom parts and fasteners are specified, and the chassis checks and test criteria are complete.
