# C2 to Feetech servo bus — build delta to CTRL-04 and RP-02 link contract

2026-10-07. D-046/D-047 select two STS3045Ms and one ST3215-HS. This page owns the build-specific servo side of [CTRL-04](../../02-prototypes/RP-01-head/decision.md) and the [RP-02 link contract](../../02-prototypes/RP-02-electrical/link-contract.md). The C2↔C3 RS-422 framing, `HEAD_STATE` public fields and timing contract remain those of RP-02; the internal servo transport becomes Feetech magnetic ST-series half-duplex TTL. The [actuator screen](../03-head/v1/feetech-actuator-screen.md) owns the register/protection and physical gates.

## Wire and packet contract

- One `SERVO_DATA` net leaves PCB-12, runs through PCB-14/W43/PCB-08 and reaches the body-fixed yaw branch `W15`. Pitch and roll use the same net inside the head. Supplies are separate: 5.5 V setpoint for pitch/roll, 12 V for yaw. Signal reference crosses the cassette; no 12 V signal pull-up is permitted. The STS3045M [datasheet](https://pages.switch-science.com/comparison/files/feetech/serial-sts/STS3045M_datasheet.pdf) accepts 2–5 V logic high and 0–0.45 V low. Confirm ST3215-HS VIH/VIL, output high and unpowered-port leakage on B5 before the PCB-12 transceiver is frozen.
- The [Feetech magnetic encoder protocol](https://www.feetechrc.com/Data/feetechrc/upload/file/20240702/%E8%88%B5%E6%9C%BA%E5%8D%8F%E8%AE%AE%E6%89%8B%E5%86%8C-%E7%A3%81%E7%BC%96%E7%A0%81%E7%89%88%E6%9C%AC.pdf) frames `FF FF ID LENGTH INSTRUCTION PARAMETERS CHECKSUM`; checksum is bitwise NOT of the low byte of the sum from ID through parameters. Multi-byte values are little-endian. `PING=0x01`, `READ=0x02`, `WRITE=0x03`, `REG_WRITE=0x04`, `ACTION=0x05`, `SYNC_READ=0x82`, `SYNC_WRITE=0x83`; status packets carry an error byte. This is **not** Dynamixel Protocol 2.0 framing or CRC.
- Assign IDs with one servo attached at a time: yaw 1, pitch 2, roll 3. The official [magnetic memory table](https://www.feetechrc.com/en/letter-of-agreement.html) says address 5 is ID, 6 baud (code 0 = 1 Mbps), 55 EEPROM lock, 56 position, 58 speed, 62 voltage, 63 temperature, 65 error flags and 69 current (6.5 mA/count). Read the received model/firmware version first; the generic table is a family map, not proof every revision implements current feedback identically.
- C2 sends bounded position goals at ≥100 Hz only while armed. It reads position, speed, voltage, temperature and error flags at ≥100 Hz per axis if the bus turnaround budget permits, and current only after B1 validates that field. Timestamp the actual response capture for `HEAD_STATE`; a command write is not an encoder sample. Log timeout, checksum failure, duplicate ID, implausible position jump and stale feedback distinctly.
- Position unit is `360°/4096 = 0.087890625°/count`; an axis-specific sign and zero transform maps physical yaw/pitch/roll to servo counts. At yaw centre 2048, the requested ±58° firmware limit is counts **1388–2708** before sign reversal. The usable authored yaw limit remains ±55°, motion-envelope sweep ±61° and hard stop ±62° until the refitted CAD check changes them. A cold boot reads actual counts with torque off and never treats a stored centre as proof of physical alignment.

## Fault and commissioning sequence

1. Bring up PCB-12 with the servo torque disabled and the hardware `MOTOR_PERMIT` open. Verify the bus line is at a valid low/high level at all three far endpoints with yaw at 12 V and head at its 5.23 V minimum.
2. Commission one servo at a time: read model/firmware and ID, unlock EEPROM, set unique ID and 1 Mbps, load position mode and mechanical min/max limits, set both dead zones to one count, configure voltage/current/overload protection from measured B1 values, relock EEPROM, cycle power and read back.
3. With the coupled mechanism supported, establish each zero/sign using an external angle reference. Write yaw limits only after confirming the ±58° counts do not cross the ±62° stops in either direction. Verify pitch/roll limits against the new envelope.
4. Arm only after all IDs answer, limits and protection read back, the rail and `HEAD_PGOOD` are valid, and `HEAD_OC` is clear. Ramp goals from the actual measured pose; do not jump to 2048. C2 imposes the storyboard's 70% cap on the fastest pitch profiles.
5. On missing feedback, current/voltage/temperature fault, inconsistent position or expired command age, inhibit new goals, send torque-off (`address 40 = 0`) when communication still works, and drop `MOTOR_PERMIT` through the independent hardware path. Latch the event until a fresh arm after diagnosis. Feetech's overload flag may clear when a new position goal is sent, so no fresh goal may escape while faulted.

PCB-12's current half-duplex transceiver is **not yet accepted** on paper: its output-high source, 3.3 V input tolerance, direction-enable timing, line pull-up location, contention current and unpowered backfeed need schematic values and a B5 mixed-rail bus test. The old Dynamixel Current-based Position Mode 5, `Shutdown=0x35` and 100 ms Bus Watchdog settings must not be copied into firmware. The physical latching protector and independent current monitor described in [power-boards](power-boards.md#4a-feetech-actuator-rail-delta-d-046d-047-2026-10-07) remain separate from C2's fault latch.
