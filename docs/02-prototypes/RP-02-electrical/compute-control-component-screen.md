This screen answers “what can implement Part 3?” It does not turn a datasheet or storefront listing into qualification evidence. A selected architecture row can still require a physical sample and can still fail G04/G05.

## 1. Disposition vocabulary

| Label | Meaning |
|---|---|
| `SELECTED` | The architecture fixes this exact product or family. Purchase and validation can remain open |
| `LEAD` | Best current implementation candidate; do not freeze the schematic or order until its named evidence closes |
| `BENCH` | Useful for the rig but not an installed production answer |
| `FALLBACK` | Change-controlled substitute after the lead fails a stated criterion |
| `REJECT` | Violates a fixed requirement or creates unnecessary scope |
| `DEFER` | Owner is a later prototype and required inputs do not yet exist |

## 3. Shortlist conclusions

### Purchase-ready when the builder authorizes

These selections have no remaining architecture fork, but still need incoming inspection and qualification:

1. Raspberry Pi 5 2 GB (`CCD-CMP-01`);
2. official Raspberry Pi 5 Active Cooler (`CCD-CLG-01`);
3. the selected no-touch display SKU 30493 (`CCD-DSP-01`);
4. an official ESP32-S3-DevKitC-1-N8R8 for the C2 bench twin and an official **DevKitC-1-N8** for the C3 prototype (`CCD-HMC-02`, `CCD-BMC-01`);
5. the already-selected headerless Waveshare ESP32-S3-Zero C2 (`CCD-HMC-01`) when its purchase is authorized.

Buy one working unit plus one spare only where the workbench/repair strategy calls for it. A listing is not proof of genuine silicon; record photographs, package/board revision, measured mass where relevant and invoice/supplier in the receiving record.

### Do not buy before schematic/test conditions exist

- Differential transceivers: retain THVD1451D SOIC as the prototype lead; compare the cheaper ISL83077E only with protection/termination, startup state and complete carrier cost. Freeze package with the assembler.
- TPS3436-Q1: choose exact timing/latch variant only after measuring boot and loop windows.
- Pi storage: qualify the 32 GB official A2 lead against the actual image/log/update footprint. Do not treat the staged SanDisk price as a purchase option; compare endurance media only if a real orderable price or measured write-endurance failure justifies it.
- C2/C3 carrier PCBs: wait for servo family and RP-03 driver/sensor interfaces respectively.
- Any ROS/micro-ROS-specific board or adapter: no V1 requirement exists.
