## Compute & control

`RP02-P3-REG-01` fixes the C0/C2/C3/D1 ownership: the display carrier renders the face, C2 owns head trajectories/safety, C3 owns base control/local hazards, and the Pi owns semantic behaviour/perception. Production MCU links are differential UART and C2 relays display state locally. Rows below are candidates unless explicitly marked selected; detailed `CCD-*` evidence lives in `RP-02-electrical/compute-control-component-screen.md`.
